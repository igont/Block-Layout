# FB Layout

FB Layout - проект нового движка раскладки ForestBrick на Rust. Целевое ядро восстанавливает канонические оси и связи стен, согласует мировую и локальные сетки, учитывает конструктивные ограничения и выпускает блоки только по проверенному полному плану.

Поддерживаемый целевой объём: ортогональные стены и стены под 45° в плане, верхние этажи, проёмы, балки вдоль и поперёк, перемычки и признаки спила шипов. Координаты нормализуются до 0,01 мм; некратная длина компенсируется рядовым кирпичом с сохранением каталожной геометрии соединений.

Реализация Rust ещё не создана. [Дорожная карта](<Документация/Дорожная карта/00 Дорожная карта.md>) содержит 12 этапов с зависимостями и приёмкой; ближайший этап создаёт типы точности и явную топологию. [Карта документации](<Документация/00 Карта документации.md>) объединяет парадигмы, TDR и внешние контракты.

Старый Java-движок служит источником конструктивных примеров. [Сохранённые фикстуры](<tests/fixtures/README.md>) характеризуют прежнее поведение и не заменяют независимые нормативные ожидания.
